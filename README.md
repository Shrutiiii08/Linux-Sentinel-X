# Linux-Sentinel-X

## Linux System Monitoring, Process Supervision and Recovery System

### Project Type
Individual Capstone Project

### Programming Language
C++

### Operating System
Linux

### Project Objective

Linux-Sentinel-X is a Linux-based system monitoring and process supervision project designed to monitor important system resources and processes, detect abnormal conditions, and perform controlled recovery actions.

The project also incorporates Linux system programming concepts and a Linux character device driver component.

### Main Components

- System Resource Monitoring
- Process Monitoring
- Process Supervision
- Failure Detection
- Recovery Management
- Logging
- Linux System Programming
- Linux Character Device Driver
- C++ Object-Oriented Programming
